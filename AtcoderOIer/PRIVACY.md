# AtCoder AI Translator 隐私政策

生效日期：2026 年 10 月 7 日

AtCoder AI Translator（以下简称"本扩展"）尊重并保护用户隐私。本政策说明本扩展对信息的收集、使用与存储方式。

## 我们收集的信息

**本扩展不收集、不上传任何个人信息。**

- **API Key**：用户自行填写的大模型 API Key 仅保存在用户本机浏览器的 `chrome.storage.sync` 存储区中，用于直接向用户配置的 AI 服务商发起翻译请求。本扩展不会将 API Key 发送至任何第三方（AI 服务商除外，这是翻译功能的必要环节）。
- **配置项**（接口地址、模型、目标语言等）：同样只保存在本机浏览器存储中。
- **翻译缓存**：翻译结果以原文哈希为键缓存在本机 `chrome.storage.local` 中，用于加速重复访问，不会上传。
- **额度记账**：本月已用字符数保存在本机，用于额度控制功能，不会上传。

## 数据共享

除向用户在设置中明确指定的 AI 服务商发送待翻译文本与 API Key（翻译功能的必要请求）外，本扩展不与任何第三方共享数据。

本扩展不包含任何分析、统计、广告或追踪代码。

## 数据安全

- 所有敏感数据仅存储于用户本机浏览器，卸载扩展即全部删除。
- 翻译请求通过扩展后台（service worker）发出，API Key 不经过任何中间服务器。
- 网页正文仅在用户主动点击翻译按钮时才会被读取并发送。

## 权限说明

- `https://atcoder.jp/*`：仅在 AtCoder 网站页面内提供翻译按钮与译文展示。
- API 域名权限（OpenAI / DeepSeek / Moonshot / 阿里云百炼 / Anthropic 等）：用于向用户在设置中指定的 AI 服务商发送翻译请求，扩展不会访问这些域名之外的其他站点。

## 变更

如本政策更新，将在扩展商店页面同步更新。继续使用本扩展即表示接受更新后的政策。

## 联系方式

如有隐私相关问题，请通过扩展商店的支持渠道联系开发者。
